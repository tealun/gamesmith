# 上线清单

逐项勾选；不做的项写明「延后 + 触发条件」。平台相关条目**以官方文档为准**，标「待核实」的提审前必须关闭或有兜底。

## A. 资质与备案

- [ ] 正式名称已定，官方商标检索完成并留证据；简称已设（如平台支持）。
- [ ] 账号主体与服务类目确认；类目对个人主体的限制已查。
- [ ] 资质路线确认（IAA / 虚拟支付需版号等，见 `compliance.md`）。
- [ ] 备案：游戏类型、网络类型（单机/联网）及依据写入合规文档。
- [ ] 备案文字按当前版本如实填写：场景、玩法、背景、角色、系统功能（只选实际存在的）。
- [ ] 备案截图：每栏数量达标、**不同模块不复用同一张**、截图内游戏名为当前名称；是否必须真机截图——待核实/以平台为准。

## B. 合规内容

- [ ] 启动页全文显示《健康游戏忠告》。
- [ ] 后台选择适龄提示等级。
- [ ] 隐私：不处理个人信息 → 后台确认「承诺未处理」；用关系链 → 隐私指引 + 授权弹窗。
- [ ] 字体：烘焙文字的字体可商用，许可证入库；界面用系统字体或已授权字体。
- [ ] 素材、音效、音乐来源与授权记录完整。
- [ ] 分享：无强制分享、无分享换奖励、分享图文与游戏相关。

## C. 构建与包体

- [ ] 构建模板为**正式 AppID**、方向正确（校验脚本通过）。
- [ ] 关闭 Debug；引擎模块已裁剪；主包与总包在限内（以官方当前上限为准）。
- [ ] 首帧加载页；分包下载失败可重试。
- [ ] 新资源 meta 已生成并提交；同步脚本已跑，副本未手改。
- [ ] 源码扫描测试通过（编译目标坑）。

## D. 开关与版本

- [ ] 所有测试开关关闭或改为正式值（无尽全开放、无敌、跳关、调试面板）。
- [ ] 限时活动 `from / until` 改为实际日期。
- [ ] 版本号更新（如 1.0.0），并在标题页/设置页可见。
- [ ] 存档结构带版本号，旧存档可读。

## E. 质量

- [ ] `validate_config`、`npm test`、`typecheck`、求解器全量通过（附命令输出）。
- [ ] 预览工具全部界面截图评审通过。
- [ ] 真机：iOS + 安卓各至少一台，完整通关主流程；刘海机型检查 HUD 与胶囊。
- [ ] 中低端安卓帧率检查（性能面板截图）。
- [ ] 切后台自动暂停；断网/弱网下分包加载失败有提示。
- [ ] 音乐无爆音；震动在真机正常；静音可玩。

## F. 数据

- [ ] 埋点事件已在后台逐个创建（事件名与字段与代码一致）。
- [ ] 编码表定稿（场景码等上线后不可改）。
- [ ] 指标阈值（继续/调整/停止）与评估样本量写进文档。
- [ ] 能按片段/关卡统计死亡率。

## G. 提审材料

- [ ] 图标（示例项目备 512 与 144 两种；所需尺寸待核实/以平台为准）。
- [ ] 截图、简介；尺寸与数量以平台为准。
- [ ] 提审材料统一使用正式名称。

## H. 上线后第一周

- [ ] 每日看留存、单局时长、新手关通过率、片段死亡率排行。
- [ ] 真机问题按 `playtest-loop.md` 闭环处理。
- [ ] 下一批内容（场景/关卡）按数据决定是否放出。
