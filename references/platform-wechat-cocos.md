# 平台接入：微信小游戏 + Cocos Creator

> 本文来自示例项目在 **Cocos Creator 3.8.8 + 微信开发者工具（2026-10/11）** 上的实测与官方文档核实。编辑器菜单名、上限数字会随版本变化，**以官方文档与你本机界面为准**。其他引擎/平台（抖音、Laya、Phaser 等）按相同结构补写，事实先核实。

## 1. 包体与分包

已核实（微信官方「分包加载」文档，2026-04 版本）：

| 项 | 上限 |
|---|---|
| 主包 | ≤ 4 MB |
| 主包 + 全部分包 | ≤ 30 MB |
| 普通分包单个 | 不限（受总量限制） |
| 独立分包 | ≤ 4 MB |
| 开放数据域目录 | 不能设为分包 |
| 远程资源 | 域名须后台配置、仅 https、**须 ICP 备案** |

实测做法（Cocos 3.8.8）：
1. **引擎模块裁剪**：只保留实际用到的（2D 游戏示例：Audio、WebGL、Basic 2D、Graphics、UI），未裁剪时主包实测约 6.4 MB，超限。
2. 裁掉 3D 后，**关掉场景根节点的 Skybox**（以及 Fog、Shadows），否则启动报 `Cannot read property 'createMesh' of undefined`。
3. 构建**不勾 Debug**（未压缩引擎会撑爆主包）。
4. 资源放分包：Bundle Config 新建配置，小游戏标签下勾「独立配置」，微信一行压缩类型选「小游戏分包」。
5. 预览报错 `80051 source size … exceed max limit 4MB` = 主包超限，按 1–4 排查。

## 2. 首帧加载画面

- 坑：引擎会在**显示第一帧之前**加载 `resources` 目录，分包下载期间是黑屏。
- 做法：资源放在**自定义 Bundle**（非 `resources`），启动组件第一帧先画加载页（可复用主角绘制代码，用矢量画，不依赖图集），再 `assetManager.loadBundle(...)`；下载失败显示「点屏幕重试」。
- 场景图集**按需加载**且「必定结束」：成功、失败、出错、超时（示例 8 秒）任一发生即放行，该场景先不画精灵；原因记控制台**并显示在屏幕上**。
- 等资源时的重复点击要去重，否则积压的开局会稍后一起触发造成卡顿；能不等的模式（如无尽）立即开局、后台补加载。
- 启动耗时（下载 / 引擎初始化 / 分包加载）需真机测量；是否启用「分离引擎」插件、引擎启动 logo 能否去除——**待核实**。

## 3. 构建模板与配置入库

- 构建设置与 Bundle 配置会写进工程文件（示例：`settings/v2/packages/builder.json`、`assets/<bundle>.meta`），**入库**。
- 微信构建模板 `build-templates/wechatgame/project.config.json` 每次构建覆盖产物：
  - `appid` 为空 → 开发者工具回到游客模式，预览/真机调试变灰；
  - 测试号要选**小游戏**测试号，误用小程序测试号会报「未找到 app.json」；
  - 正式 AppID 预览需要扫码者是该小游戏的管理员或开发者。
- 横屏游戏：构建面板 Orientation 与模板/`game.json` 的 `deviceOrientation` 都要是 landscape，否则手机上画面是竖的。
- 用校验脚本检查模板：`appid` 匹配 `^wx[0-9a-f]{16}$`、方向与设计一致。

## 4. 编译目标的坑（ES5）

- 实测：微信构建把 `[...new Set(arr)]` 编成 `[Set]`（数组里只有一个 Set 对象），逻辑静默出错（示例：已解锁场景列表变成 Set 对象，场景图集永远加载不到，无尽模式进不去）。
- 做法：用 `Array.from(set)`；对 Set/Map 也避免 `for…of` 与展开 `.keys()/.values()/.entries()`。
- 防线：一条源码扫描测试，遍历核心与画面代码，匹配 `\[\.\.\.new (Set|Map)\b` 与 `\.\.\.(\w+\.)?(keys|values|entries)\(\)` 即失败（骨架见 `templates/test/core.test.mjs`）。
- 教训：先看「为什么等不到」，而不是加超时掩盖。该 bug 先表现为「加载场景中…」卡住，加超时只是让它不卡，根因在列表类型。

## 5. 真机调试与屏幕报错

- iOS 真机调试需要数据线连电脑（示例项目经验；具体条件以开发者工具文档为准，**待核实**），测试者手机上通常看不到控制台。
- 因此：点击处理、每帧更新包 try/catch，出错时**在屏幕底部显示错误**并记日志；加载状态显示正在等哪个资源（如「加载场景中…<场景名>」）；失败提示显示数秒不被随后的界面清掉。
- 调试日志保留最近 N 条在全局变量（如 `globalThis.__gameLog`），方便真机调试面板查看。
- 开发者工具模拟器不会震动，也不一定有声音，以手机为准。

## 6. 开发者工具与缓存（经验，待核实）

示例项目反馈：开发者工具升级后模拟器可能卡死；手机上会缓存旧分包，看起来「改了没生效」。仓库文档未留下具体版本与复现证据，以下为通用排查，**待核实**：
- 改了代码：Cocos 重新构建 → 开发者工具「编译」→ 再预览扫码。
- 怀疑缓存：开发者工具清缓存后重新编译；手机上删除最近使用里的小游戏后重新扫码；在标题页显示版本号与关键开关状态（示例：「测试版：无尽全场景开放」），一眼确认包内配置。
- 模拟器异常：换稳定版或回退版本，直接用真机预览验证。

## 7. 引擎 meta 文件

- Cocos 为每个资源生成 `.meta`（含 uuid），场景/预制体按 uuid 引用；**必须入库**。首次打开工程生成的 meta 与主场景要提交。
- 脚本生成的新资源（图集、音频、配置、脚本）没有 meta 时，各机器打开会生成不同 uuid。做法：写 `make_metas` 脚本，按同类型已有 meta 作模板、换新 uuid 生成；烘焙/渲染/同步后运行。
- 同步脚本保留 meta、删除源已不存在的文件时连同 meta 一起删。
- `.gitignore` 排除 `library/`、`temp/`、`build/` 等缓存。

## 8. 横屏安全区

- 胶囊位置：`wx.getMenuButtonBoundingClientRect()`（屏幕左上角为原点）。
- `wx.getWindowInfo().safeArea` 按**竖屏正方向**给出且部分机型缺失，横屏须自行换算并兜底（已核实）。
- 实测示例（模拟器 iPhone 12/13 横屏）：胶囊 L746 T12 R834 B44，窗口 844×390；真机与刘海机型**待测**。
- 启动组件把测量值显示在屏幕角落，测试者截图即可回传。HUD、按钮、触控分区避开胶囊与刘海。

## 9. 埋点（整数编码）

- 通道 `wx.reportEvent`（基础库 ≥ 2.14.4），事件须先在后台「指标事件管理」创建；**上报值仅支持整型**（已核实）。配额未公开（待核实）。
- 设计编码表放配置（如 `analytics_codes.json`）：
  - 枚举（result、kind、placement）→ 小整数；
  - 字符串 id → 结构化整数，例：`片段码 = 场景码×10000 + 难度×100 + 序号`，`敌人码 = 场景码×100 + 编号`；
  - 浮点 → 毫秒或 ×100 取整。
- **场景码等编码上线后不可改**，新增只追加。
- 高频事件（拾取、踩踏）采样（示例 10%）；上报 try/catch，失败不影响游戏；编辑器里打印日志。
- 编码函数写在不依赖引擎的模块里并单测。

## 10. 分享

已核实（微信官方文档）：
- 分享卡 `query` 为 `k1=v1&k2=v2`，接收方用 `wx.getLaunchOptionsSync()` / `wx.onShow()` 读取；分享图比例 **5:4**。
- 好友排行用开放数据域（主域可发消息给开放数据域，反向不行）；群排行 `wx.getGroupCloudStorage` 只能在从群分享卡片打开时、在开放数据域内调用，需授权。使用关系链须做隐私指引与授权弹窗（见 `compliance.md`）。
- 诱导分享禁令见 `compliance.md`。

实现：`wx.showShareMenu({ menus: ['shareAppMessage', 'shareTimeline'] })`，接口不存在时静默跳过；卡片标题进配置；不做分享换奖励。朋友圈分享是否可用**待核实**。

## 11. 其他平台适配要点

- 生命周期：`onHide` 自动暂停，`onShow` 不自动继续（由玩家点继续）。
- 震动：`wx.vibrateShort({ type })` 的 type 支持度待核实，调用包 try/catch，失败静默；震动档位按事件进配置。
- 音乐：只在「想播的曲目变化」时重启，**不要**根据 `AudioSource.playing` 每帧判断重启——微信启动或缓冲时它会短暂为 false，导致真机「喀喀」声（实测）。
- 存档：`cc.sys.localStorage` 在小游戏中即微信本地存储；经平台层封装。

## 12. 环境搭建指引怎么写

- 写给非程序员：每步一个动作，菜单写中英文名，标注「首次做一次（结果入库）」与「每次构建」。
- 写清预期现象（「左侧模拟器应出现开始页」）与常见问题表（现象 → 处理）。
- 列出「需要发给开发助手的证据」（录屏、胶囊测量截图、机型）。
- 编辑器无法在云端运行时，说明哪些步骤只能本人点选，其余（同步、校验、提交）可由助手远程执行。
