# 上线清单

逐项勾选；不做的项写明「延后 + 触发条件」。平台相关条目**以官方文档为准**，标「待核实」的提审前必须关闭或有兜底。

每条后面的标记是验证方式：**[仓库]** 读文件或跑命令就能确认；**[后台]** 只能在平台后台确认；**[真机]** 只能在手机上确认。Agent 汇报时每条用三种状态之一：

- **已有证据**：写出证据（文件路径、命令输出、截图）。
- **缺失**：仓库里应该有但没有。
- **需本人提供证据**：[后台] / [真机] 项，或仓库里查不到的构建设置。写明要什么证据，例如「构建面板截图」「后台适龄设置截图」。

## A. 资质与备案

- [ ] [仓库/后台] 正式名称已定，官方商标检索完成并留证据；简称已设（如平台支持）。
- [ ] [后台] 账号主体与服务类目确认；类目对个人主体的限制已查。
- [ ] [仓库] 资质路线确认并写进合规文档（IAA / 虚拟支付需版号等，见 `compliance.md`）。
- [ ] [仓库] 备案：游戏类型、网络类型（单机/联网）及依据写入合规文档。
- [ ] [仓库] 备案文字按当前版本如实填写：场景、玩法、背景、角色、系统功能（只选实际存在的）。**对照当前配置核对**：版本号、场景数、关卡数、模式与备案文字一致；内容扩展后备案材料最容易过时。
- [ ] [仓库] 备案截图：每栏数量达标、**不同模块不复用同一张**、截图内游戏名为当前名称、覆盖当前全部场景；是否必须真机截图——待核实/以平台为准。

## B. 合规内容

- [ ] [仓库] 启动页全文显示《健康游戏忠告》。
- [ ] [后台] 选择适龄提示等级。
- [ ] [后台] 隐私：不处理个人信息 → 后台确认「承诺未处理」；用关系链 → 隐私指引 + 授权弹窗（弹窗代码 [仓库]）。
- [ ] [仓库] 字体：烘焙文字的字体可商用，许可证入库；界面用系统字体或已授权字体。
- [ ] [仓库] 素材、音效、音乐来源与授权记录完整：有一份统一的授权清单，自制或程序生成的素材也记一行（见 `compliance.md` 第 5 节）。
- [ ] [仓库] 分享：无强制分享、无分享换奖励、分享图文与游戏相关。

## C. 构建与包体

- [ ] [仓库] 构建模板为**正式 AppID**、方向正确（校验脚本通过）。
- [ ] 关闭 Debug；引擎模块已裁剪；主包与总包在限内（以官方当前上限为准）。引擎裁剪通常写进工程设置 [仓库]；Debug 是每次构建面板里的选项，主包大小要看构建产物 [需本人提供：构建面板截图、构建输出或开发者工具里的包体大小]。见 `platform-wechat-cocos.md` 第 3 节。
- [ ] [仓库] 首帧加载页；分包下载失败可重试。
- [ ] [仓库] 新资源 meta 已生成并提交；同步脚本已跑，副本未手改。
- [ ] [仓库] 源码扫描测试通过（编译目标坑）。

## D. 开关与版本

- [ ] [仓库] 所有测试开关关闭或改为正式值（无尽全开放、无敌、跳关、调试面板）。
- [ ] [仓库] 限时活动 `from / until` 改为实际日期；按提审和备案的预计时长倒推，确认上线时活动还没过期。
- [ ] [仓库] 版本号更新（如 1.0.0），并在标题页/设置页可见。
- [ ] [仓库] 存档结构带版本号，旧存档可读。

## E. 质量

- [ ] [仓库] `validate_config`、`npm test`、`typecheck`、求解器全量通过（附命令输出）。求解器全量很慢时，可以引用最近一次全量输出作为证据，前提是那次之后片段、核心和手感配置都没有改动（附提交号）；否则按场景分片并行跑完。
- [ ] [仓库] 预览工具全部界面截图评审通过。
- [ ] [真机] iOS + 安卓各至少一台，完整通关主流程；刘海机型检查 HUD 与胶囊。
- [ ] [真机] 中低端安卓帧率检查（性能面板截图）。
- [ ] [真机] 切后台自动暂停；断网/弱网下分包加载失败有提示（代码 [仓库]）。
- [ ] [真机] 音乐无爆音；震动在真机正常；静音可玩。

## F. 数据

- [ ] [后台] 埋点事件已在后台逐个创建（事件名与字段与代码一致）。
- [ ] [仓库] 编码表定稿（场景码等上线后不可改）。
- [ ] [仓库] 指标阈值（继续/调整/停止）与评估样本量写进文档。
- [ ] [仓库] 能按片段/关卡统计死亡率。

## G. 提审材料

- [ ] [仓库] 图标（示例项目备 512 与 144 两种；所需尺寸待核实/以平台为准）。
- [ ] [仓库] 截图、简介；尺寸与数量以平台为准。
- [ ] [仓库] 提审材料统一使用正式名称。

## H. 上线后第一周

- [ ] 每日看留存、单局时长、新手关通过率、片段死亡率排行。
- [ ] 真机问题按 `playtest-loop.md` 闭环处理。
- [ ] 下一批内容（场景/关卡）按数据决定是否放出。
