# Privacy Policy

Last updated: 2026-11-05

Gamesmith is a skill for Claude: written instructions plus small skeleton scripts that you copy into your own game project. It connects to no server and adds no MCP servers, hooks or commands.

- **We collect nothing.** The plugin does not collect, store, transmit or sell any personal data, usage data or content.
- **Your conversations stay between you and Claude.** When the skill runs, Claude reads its instructions inside your session. How Anthropic handles your conversations is governed by Anthropic's own privacy policy, not by this plugin.
- **The skeleton scripts work on local files only.** `gamesmith/templates/` holds a config validator, a level solver, a preview tool, a sync script and tests. They run only when you or Claude start them in your project, read and write files on your machine, and make no network requests. The preview tool starts a local headless browser to draw images; it loads no web pages.

Questions: open an issue at https://github.com/tealun/gamesmith/issues.

# 隐私政策

最后更新：2026-11-05

Gamesmith 是一个给 Claude 用的技能：一组说明，加上你复制到自己游戏项目里的小型骨架脚本。它不连接任何服务器，也不添加 MCP 服务器、hooks 或命令。

- **不收集任何数据。** 插件不收集、存储、传输或出售任何个人数据、使用数据或内容。
- **对话只在你和 Claude 之间。** 技能运行时，Claude 在你的会话里读取技能说明。Anthropic 如何处理你的对话，适用 Anthropic 自己的隐私政策，与本插件无关。
- **骨架脚本只处理本地文件。** `gamesmith/templates/` 里有配置校验、关卡求解器、预览工具、同步脚本和测试。它们只在你或 Claude 在你的项目里启动时运行，只读写本机文件，不发起任何网络请求。预览工具启动本机的无头浏览器来画图，不加载任何网页。

有问题请在 https://github.com/tealun/gamesmith/issues 提 issue。
